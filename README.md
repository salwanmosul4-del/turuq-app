# طرق عراقنا — مشروع التطبيق

تطبيق ملاحة اجتماعي للعراق (فكرة Waze محدّثة): بلاغات حيّة، كاميرات مراقبة وسرعة، مسارات بديلة تتجنب المقطوع والمغمور، وخرائط تُحدَّث تلقائياً.
**يعمل على:** أندرويد، Android Auto، Android Automotive OS، iPhone، CarPlay.

## ⚠ الحالة الصادقة
- **لم يُترجَم (compile) ولم يُشغَّل** أي كود أندرويد أو iOS هنا؛ بيئة الإنشاء لا تصل إلى Maven/Google/Apple. توقّع إصلاحات صغيرة عند أول مزامنة في Android Studio / Xcode (أرقام الإصدارات في `gradle/libs.versions.toml` و`ios/project.yml` تقريبية).
- **اختُبر فعلاً:** منطق الخادم (`server/logic.py`) بسبعة اختبارات: تطبيع العربية والبحث، فك الـpolyline، دمج البلاغات والتصويت والإبلاغ عن المسيء والانتهاء، ربط البلاغات بالمسار، تحديد المعدّل، تعليمات المناورات. `main.py` و`tools/*` يمرّون فحص الصياغة فقط.
- **أخطر نقطة تقنية:** رسم MapLibre على شاشة السيارة (`car/.../CarMapRenderer.kt`) عبر VirtualDisplay. جرّبه على Desktop Head Unit ثم سيارة حقيقية قبل أي وعد بالموعد.
- افتراض يجب التحقق منه: قراءة `mbtiles://` مباشرة في MapLibre Native (أندرويد وiOS). البديل: PMTiles.
- بصمات المضيفين المسموحين في `car/src/main/res/values/hosts.xml` **فارغة عمداً**؛ انسخها من أمثلة androidx.car.app الرسمية قبل نسخة الإصدار.
- `ios/` لا يحتوي مشروع Xcode جاهزاً: شغّل `xcodegen` (يقرأ `project.yml`).

## البنية
```
core/        منطق مشترك (أندرويد): نماذج، Api، NavEngine، تحديث الخرائط، MapController، سهم العلم
car/         Android Auto + Automotive: قوالب السيارة (بحث، معاينة، ملاحة، بلاغ، حالة الخرائط) + رسم الخريطة
app/         تطبيق الهاتف (Compose) + خدمة ملاحة أمامية
automotive/  حزمة Android Automotive OS (نفس applicationId، form factor مستقل في Play)
ios/         iPhone + CarPlay (Swift، يعيد استعمال نفس الخادم ونفس منطق الملاحة)
server/      FastAPI + SQLite: بلاغات، بحث معالم، توجيه Valhalla، سكربتات الخرائط
```

## المعالم والأماكن («من … إلى …»)
- يمكن اختيار **نقطة الانطلاق** (افتراضياً «موقعي») والوجهة: منطقة، مبنى، دائرة حكومية، جامعة، مستشفى، جسر، مول…
- الخادم يبحث في جدول `places` بالعربية: يزيل التشكيل، يوحّد (أ إ آ→ا، ى→ي، ة→ه)، يطابق مع/بدون «ال»، ويدعم أسماء بديلة وإنجليزية، ويرتّب بالأهمية والقرب.
- **المصدر الحقيقي للمعالم هو OpenStreetMap:** `tools/import_osm_places.py` يستخرجها من ملف العراق ثم `seed_places.py` يحمّلها. **تغطية OSM للعراق متفاوتة** (المدن الكبرى أفضل بكثير من الأطراف)، لذلك:
  - الملف المرفق `data/landmarks_seed.json` فيه ٨ معالم فقط بإحداثيات تقريبية من الذاكرة (`verified=0`) لإثبات العمل، **لا تعتمدها** قبل مراجعتها.
  - خطة الجودة: استيراد OSM → مراجعة فريق ميداني لأهم ٥٠٠–١٠٠٠ معلم في بغداد (وزارات، دوائر، جامعات، مستشفيات، جسور، ساحات) → فتح زر «اقترح تصحيحاً» للمستخدمين لاحقاً.
  - بحث Photon اختياري احتياطي (`PHOTON_URL`) إن قلّت النتائج.
- التوجيه من نقطة غير موقعك **معاينة فقط**؛ عند «ابدأ» يُعاد حساب المسار من موقعك الفعلي.

## تحديث الخرائط
1. `server/tools/build_regions.sh` يبني MBTiles لكل محافظة (Planetiler + Geofabrik) ويكتب `manifest.json` (إصدار = سنة+شهر، SHA-256، الحجم).
2. ارفع ملفات `.mbtiles` أولاً ثم `manifest.json` أخيراً.
3. التطبيق (WorkManager على أندرويد، وفحص عند الفتح على iOS) يقارن الإصدارات، ينزّل المتغيّر فقط على Wi-Fi مع استئناف، يتحقق من البصمة، ويستبدل الملف ذرّياً. على Android Auto تعمل المهمة على الهاتف، وعلى Automotive داخل السيارة.
4. جدول زمني مقترح: شهرياً لكل المحافظات، وفورياً عند تغيّر كبير (جسر جديد/طريق جديد). تحديث المقطوعات المؤقتة لا يحتاج خرائط: يأتي من البلاغات ويدخل في التوجيه فوراً.

## قائمة النشر — Google Play
- [ ] حساب مطوّر + تحقق الهوية (+ اختبار مغلق ١٢ مختبراً لمدة ١٤ يوماً للحسابات الشخصية الجديدة).
- [ ] تصنيف السيارة: «Navigation» (Android Auto) — يتطلب خدمة أمامية بإشعار ملاحة أثناء التوجيه (موجودة في `NavForegroundService`؛ **أضف CarAppExtender للإشعار** قبل المراجعة).
- [ ] اختبار الجودة للتطبيقات في السيارة (Car App Quality guidelines) على Desktop Head Unit: قوالب فقط، لا نصوص طويلة، عدّاد نقرات محدود، وضع ليلي/نهاري.
- [ ] Automotive OS: ارفع حزمة `:automotive` في مسار form factor «Automotive OS»؛ نموذج Car App quality مستقل؛ جرّب على Android Automotive emulator.
- [ ] **سياسة المحتوى من المستخدمين (UGC):** يوجد Flag + إخفاء تلقائي بعد ٣ بلاغات؛ أضف شاشة سياسة استخدام، وقناة اتصال، ومراجعة بشرية للمبلَّغ عنه.
- [ ] سياسة الخصوصية (رابط داخل التطبيق وفي المتجر): الموقع (أثناء الاستخدام + الخلفية للملاحة)، معرّف الجهاز العشوائي، البلاغات؛ نموذج Data safety؛ تصريح استخدام الموقع في الخلفية مع فيديو توضيحي.
- [ ] مراجعة قانونية لتنبيهات الكاميرات في العراق (قد تُقيَّد في بعض الدول). المشروع يعرضها كبلاغات مجتمع للسلامة المرورية؛ **أي بلاغ عن مواقع أمنية/عسكرية مقيَّد**.
- [ ] ملف AAB موقّع، Play App Signing، ProGuard مفعّل (قواعد في `app/proguard-rules.pro`)، لقطات شاشة بالعربية، وصف RTL.

## قائمة النشر — Apple
- [ ] Apple Developer Program (٩٩$/سنة).
- [ ] **CarPlay:** اطلب صلاحية «CarPlay Navigation» من Apple (com.apple.developer.carplay-maps) — تُمنح بعد مراجعة، وقد تستغرق أسابيع. بدونها يعمل تطبيق الهاتف فقط.
- [ ] مراجعة App Review 1.2 (UGC): فلترة، إبلاغ، حظر، تواصل.
- [ ] Privacy Nutrition Label، وصف استخدام الموقع (موجود في `project.yml`)، TestFlight قبل الإصدار.
- [ ] خلفية iOS: تنزيل الخرائط الخلفي الحقيقي يحتاج `URLSession(background:)` و`BGAppRefreshTask` (النسخة الحالية أمامية).

## تشغيل الخادم
```
cd server && python -m unittest discover -s tests
pip install -r requirements.txt
python seed_places.py turuq.db data/landmarks_seed.json
VALHALLA_URL=http://localhost:8002 uvicorn main:app --port 8000
```
Valhalla يحتاج بناء بلاطات التوجيه من iraq-latest.osm.pbf (راجع وثائق Valhalla)، وأي خادم HTTPS (Caddy/Nginx) أمام FastAPI، ومساحة تقديم ملفات ثابتة للخرائط مع دعم Range.
**قبل الإطلاق غيّر** `api.turuq.example` و`maps.turuq.example` و`tiles.turuq.example` في `core/build.gradle.kts` وفي ملفات iOS.

## طريقة العمل بدون مطوّر سيارات: حلقة «ابنِ ← الصق الخطأ ← أصلحه»
لا أستطيع ترجمة الكود هنا، لكن GitHub يستطيع. المسار الموصى به:
1. أنشئ حساباً على github.com ومستودعاً خاصاً (Private) وارفع محتوى هذا المجلد.
2. سيعمل تلقائياً `.github/workflows/android.yml`: يبني التطبيق ويشغّل اختبارات الخادم، ويعرض أخطاء الترجمة إن وجدت (تبويب Actions).
3. انسخ نص الخطأ والصقه لي (أو لأي مساعد)، فأصلح الملف المعني. كرّر حتى يصبح البناء أخضر. هذا هو الطريق الواقعي لإيصال الكود من «مكتوب» إلى «يُترجَم».
4. بعد الأخضر: نزّل ملف APK من نفس الصفحة وثبّته على هاتفك. ثم جرّب على Desktop Head Unit (جزء من Android Studio) للسيارة. iOS: شغّل `ios.yml` يدوياً (يحتاج مشغّل macOS).
**تنبيه صريح:** اختبار السيارة الحقيقية (الخريطة على الشاشة) لا يمكن إنجازه من بعيد؛ يلزم شخص يجرّب بسيارة أو محاكٍ ويرسل لقطات وسجلات.

## البيانات الحقيقية (تشغيل على خادم)
`server/deploy/` فيه docker-compose جاهز: Valhalla (توجيه) + الخادم + Caddy (HTTPS وملفات الخرائط).
```
cd server/deploy
# عدّل النطاقات في Caddyfile و docker-compose، ووجّه DNS إلى الخادم
bash setup_data.sh baghdad        # تجربة ببغداد وحدها أولاً، ثم بدون وسيط لكل المحافظات
```
يقوم السكربت بتنزيل ملف العراق من OSM، استخراج المعالم، تحميلها في قاعدة البيانات، بناء الخرائط وmanifest، ثم تشغيل الخدمات. **لم يُجرَّب** (لا وصول للشبكة هنا)، وأول تشغيل سيكشف تعديلات صغيرة.
منطق دمج manifest جُرّب فعلياً بـ jq. احتياج الخادم الموصى به: ٤ نواة، ١٦ جيجا رام، ١٠٠ جيجا قرص.
